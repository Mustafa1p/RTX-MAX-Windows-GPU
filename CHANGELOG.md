# Changelog

## 0.1.0 — 2026-10-30

- Publish the documented Palit RTX 3060 Ti reference experiment and original raw measurements.
- Add English/Arabic guides, local artwork and a chart generated from those measurements.
- Add a colored read-only Windows health/installed-file/actual-boot checker.
- Add local manual/internal source builds and a staging-only installation preparation tool.
- Preserve upstream source, licenses and attribution; replace private internal partition configuration with a refusing template.
- Add result-integrity/rejection tests, a synthetic UEFI boot-parser test and publication validation.

No public firmware payload, runtime profile or universal hardware-support claim is included.
